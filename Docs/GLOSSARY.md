# Glossary

This glossary starts with a simple explanation, then gives a more technical explanation.

| Term | Simple explanation | Technical explanation |
|---|---|---|
| React | A tool for building user interfaces out of reusable pieces. | A JavaScript library for composing UI components and managing state-driven rendering. |
| Vite | A fast tool that runs the app in development and builds it for production. | A modern frontend build tool and dev server with fast module loading and production bundling. |
| TypeScript | JavaScript with type checking. | A typed superset of JavaScript that helps catch mistakes before runtime. |
| Node | The JavaScript runtime used to run server-side code. | A runtime built on Chrome’s V8 engine for executing JavaScript outside the browser. |
| Express | A lightweight web server framework. | A Node.js framework for building REST APIs and middleware pipelines. |
| MongoDB | A database that stores data in flexible documents. | A NoSQL document database that stores JSON-like BSON documents. |
| Mongoose | A helper library for MongoDB models and schemas. | An ODM that maps JavaScript objects to MongoDB collections and documents. |
| JWT | A signed token used to prove a user is logged in. | A JSON Web Token that contains claims and is signed with a secret. |
| CORS | A browser rule that controls which websites can call an API. | Cross-Origin Resource Sharing; server headers that define allowed origins and methods. |
| REST API | A web API with URL endpoints and HTTP methods. | An architectural style that uses resource-based routes such as GET, POST, PUT, and DELETE. |
| Middleware | Code that runs between a request and a response. | Express functions that can inspect, modify, or end requests before they reach a route handler. |
| Capacitor | A bridge that wraps the web app for mobile devices. | A cross-platform runtime that exposes native APIs to web code and packages apps for iOS and Android. |
| Tailwind | A CSS tool with prebuilt utility classes. | A utility-first CSS framework for composing styles directly in markup. |
| Environment Variables | Settings and secrets kept outside code. | Key-value configuration loaded from the environment at runtime or build time. |
| Authentication | Proving who a user is. | The process of verifying identity, often with passwords and tokens. |
| Authorization | Deciding what a user is allowed to do. | Access control based on identity, roles, claims, or permissions. |
| Hashing | Turning a password into a protected string. | A one-way transformation such as bcrypt hashing for secure password storage. |
| localStorage | Browser storage that keeps data after refresh. | A synchronous key-value storage API in the browser that persists across sessions. |
| HashRouter | A router that uses `#` in the URL. | A React Router implementation that stores route state in the URL fragment. |
| WebView | A browser window inside a mobile app. | A native component that renders web content inside an app shell. |
| html2canvas | A library that turns DOM content into an image. | A browser library that renders HTML and CSS into a canvas element. |
| Canvas | A blank drawing surface in the browser. | The HTML canvas element used for 2D drawing and pixel export. |
| Blob | A file-like object in browser memory. | A binary large object representing immutable raw data. |
| API base URL | The main address the frontend uses for backend requests. | The root endpoint used to build fetch URLs such as `http://localhost:5000`. |
| Route | A page location in the app. | A mapping from a URL path to a view or handler. |
| Component | A reusable piece of UI. | A React function or class that returns UI output based on props and state. |
| Props | Inputs passed into a component. | Immutable values supplied by a parent component. |
| State | Data a component remembers. | Mutable UI data managed by React that triggers re-renders when it changes. |
| Ref | A direct link to a DOM element. | A React object created with `useRef` for storing mutable values or element handles. |
