# 08 — Native / Android Integration

## Overview

The application uses **Capacitor** (v8.1.0) to wrap the web app as a native Android application. This enables access to native device APIs (camera, file system) and distribution as an APK/AAB.

---

## Capacitor Configuration

> **Source:** `capacitor.config.ts`

| Property | Value | Description |
|----------|-------|-------------|
| `appId` | `com.vintagephotobooth.app` | Android application ID / package name |
| `appName` | `Vintage Photobooth` | Display name of the app |
| `webDir` | `dist` | Directory containing the production web build |

The Android native project lives in `android/` and is auto-generated by Capacitor.

### SDK Versions (`variables.gradle`)

| Property | Value |
|----------|-------|

### Permissions (`AndroidManifest.xml`)

| Permission | Purpose |
|------------|---------|
| `INTERNET` | Network access (required for WebView) |
| `CAMERA` | Device camera access for photo capture |
| `RECORD_AUDIO` | Audio recording (available but not currently used) |
| `READ_EXTERNAL_STORAGE` | Reading files from device storage |
| `WRITE_EXTERNAL_STORAGE` | Saving photos to device Downloads folder |

### Activity Configuration

- **Launch mode:** `singleTask` (prevents duplicate activity instances)
- **Config changes handled:** orientation, keyboard, screen size, locale, density, UI mode
- **FileProvider:** Configured for secure file sharing between apps

## Platform-Specific Behaviour

The app uses `Capacitor.isNativePlatform()` to detect whether it's running inside a native WebView or in a standard browser.

### Conditionally Disabled on Native

| Feature | Reason |
|---------|--------|
| `<FilmFlicker />` | WebView SVG/CSS animation performance issues |
| `<FilmArtifacts />` | Frequent DOM updates (500ms intervals) impact WebView performance |
| `<FilmStrip />` | Complex animated borders unnecessary on native |

These overlays are purely decorative and their removal on native improves rendering performance without affecting functionality.

### Native File Save

On native Android, the download flow differs from the web:

**Web (browser):**
```
html2canvas → PNG Blob → URL.createObjectURL → <a download>.click() → URL.revokeObjectURL
```

**Native (Capacitor):**
```
html2canvas → PNG Blob → FileReader → base64 data URL → Filesystem.writeFile()
```

The file is saved to `Download/{filename}.png` in `Directory.ExternalStorage` with `recursive: true` to create the directory if needed.

## Routing Considerations

The app uses **HashRouter** (`react-router-dom`) instead of `BrowserRouter`:

```tsx
<HashRouter>
  <App />
</HashRouter>
```

This is critical for Capacitor because:
- Capacitor serves the web app from the local file system (`file://` protocol)
- `BrowserRouter` relies on server-side URL rewriting which isn't available in a native WebView
- `HashRouter` uses the URL hash (`#/camera`) which works with any protocol

## Build & Deployment

### Syncing Web Assets to Android

```bash
npm run build              # Build the production web app to dist/
npx cap sync android       # Copy dist/ to android/app/src/main/assets/public/
                           # Also syncs plugin configurations
```

### Opening in Android Studio

```bash
npx cap open android       # Opens the Android project in Android Studio
```

### Building APK/AAB

Use Android Studio's **Build > Build Bundle(s) / APK(s)** menu, or Gradle CLI:

```bash
cd android
./gradlew assembleDebug    # Debug APK
./gradlew bundleRelease    # Release AAB
```

## Gradle Warnings & Performance Notes

### 1) `Using flatDir should be avoided`

This warning appears when Gradle uses a `flatDir` repository (local folder-based dependency lookup), which does not provide dependency metadata.

For this project, unused `flatDir` and local `fileTree` jar entries were removed from:
- `android/app/build.gradle`
- `android/capacitor-cordova-android-plugins/build.gradle`

If this warning appears again after plugin updates, check whether any plugin reintroduced `flatDir` and remove it when no local `.jar/.aar` files are required.

### 2) `Build time dedicated to garbage collection`

This is informational, but frequent GC can slow builds. The project heap was increased in:
- `android/gradle.properties`

Current setting:

```properties
org.gradle.jvmargs=-Xmx2048m -Dfile.encoding=UTF-8
```

If your machine has sufficient RAM and builds are still memory-constrained, you can increase heap further (for example `-Xmx3072m`).

### 3) Java Runtime Requirement for Android Gradle Plugin

Android Gradle Plugin versions used by this project require Java 11+, and modern Android builds should use Java 17.

If Gradle fails with messages like "This build uses a Java 8 JVM", set your JDK to 17:

- In Android Studio: `File > Settings > Build, Execution, Deployment > Build Tools > Gradle > Gradle JDK`
- In terminal builds: ensure `JAVA_HOME` points to a JDK 17 installation

Quick check:

```bash
java -version
```

## Vite Base Path

The Vite configuration uses a relative base path:

```ts
export default defineConfig({
  base: './',
})
```

This ensures all asset references (JS, CSS, fonts, images) use relative URLs, which is required for Capacitor's local file serving.
